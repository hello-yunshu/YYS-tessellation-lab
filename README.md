# 奇妙的图形密铺｜苏教版五年级数学演示

基于 Vite + React + TypeScript 的数学课堂交互演示网页，用于苏教版小学五年级《奇妙的图形密铺》教学。

## 项目用途

本网页用于小学五年级数学课堂演示"图形的密铺"概念，帮助教师通过可视化、可交互的方式引导学生理解密铺的含义、判断标准和条件。

## 如何运行

```bash
npm install
npm run dev
```

开发服务器启动后访问 `http://localhost:5173`。

构建生产版本：

```bash
npm run build
npm run preview
```

## 适合的课堂环节

- **看一看**：生活导入，展示地砖、蜂巢等密铺图案
- **想一想**：对比正确密铺、有空隙、有重叠三种情况
- **试一试**：图形密铺实验室，点击不同图形查看密铺效果
- **说一说**：角度观察器，用角度解释密铺条件
- **画一画**：拖拽拼摆区，学生自由探索图形组合
- **找一找**：课堂提问，引导学生思考和讨论

## 已实现功能

1. **生活导入**：SVG 绘制的 4 种生活密铺图案（地砖、蜂巢、马赛克、拼花）
2. **密铺定义对比**：三种情况的可判断对比图
3. **图形密铺实验室**：9 种图形的密铺演示（正三角形、正方形、长方形、平行四边形、梯形、正六边形、正五边形、正八边形、正八边形+正方形）
4. **角度观察器**：围绕一点的扇形角度演示，直观解释 360° 条件
5. **拖拽拼摆区**：自由拖入图形、旋转、删除、网格吸附
6. **课堂提问**：随机生成讨论问题
7. **课堂流程侧栏**：可折叠的教学流程导航
8. **教师模式**：开关控制是否显示结论和教学提示
9. **AI 说明模式**：展示每个功能模块如何通过 AI 辅助实现
10. **总结区**：可折叠的课堂知识总结
11. **边缘显示/隐藏**
12. **顶点显示/隐藏**
13. **判断结论显示/隐藏**

## 部署到 GitHub Pages

### 方法一：GitHub Actions 自动部署

1. 将项目推送到 GitHub 仓库。
2. 进入仓库 Settings。
3. 打开 Pages。
4. Source 选择 GitHub Actions。
5. 推送到 main 分支后，GitHub Actions 会自动构建并发布。
6. 发布完成后，可通过以下地址访问：

```
https://你的用户名.github.io/sujiao-math-tiling-demo/
```

### 注意事项

如果你的仓库名不是 `sujiao-math-tiling-demo`，需要修改 `vite.config.ts` 中的 `base`：

```ts
base: "/你的仓库名/"
```

如果部署到自定义域名或根路径，可以改成：

```ts
base: "/"
```

## AI 赋能课堂展示

本项目不仅是一个数学演示网页，也用于展示 AI 如何辅助教师开发课堂工具。

### 展示方式

- **正常模式**：用于课堂投屏演示。
- **教师模式**：显示数学结论、教学提示和角度解释。
- **AI 说明模式**：显示每个功能模块背后的 AI 生成思路。
- **Ctrl / Command + 点击模块**：快速查看该模块如何由 AI 辅助实现。

### 展示重点

1. AI 可以帮助教师把教材中的抽象概念转化为可视化演示。
2. AI 可以根据课堂目标生成交互式学习活动。
3. AI 可以帮助教师快速迭代课堂问题、图形演示和教学流程。
4. 教师不需要先会完整编程，只需要能清楚描述教学目标、学生困难和课堂使用场景。
